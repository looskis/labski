# TensorFold on DGX Spark

Updated 2026-11-20. TensorFold publishes an inference engine and a hardware-filtered recipe catalog. The catalog credits Mia’s AI Lab for several Spark deployments. The engine’s family pages identify supported checkpoint formats, kernel paths and hardware qualification. A recipe links the launch command to setup instructions, memory estimates, checkpoint details and benchmark evidence. [Catalog](https://tensorfold.dev/recipes/) · [Versioned engine recipe book](https://github.com/ashhart/TensorFold/blob/v1.2.9/docs/recipes/README.md)

On November 20, Mia’s two-Spark GLM-5.3-Flash recipe moved to TensorFold 1.3.0 at `81de26f6`. Its release notes report 39.5 greedy output tok/s with DFlash2, eight available request slots and a 6 GiB prompt cache. The update includes programmatic dependent launches for GLM decode kernels. The lab’s measured 4.3% gain at 32K used the preceding `f350cd3e` engine and measures cold prefill. A matched run on the new engine is needed to establish whether that gain carries forward. [Upstream November 20 changelog](https://github.com/MiaAI-Lab/GLM-5.3-Flash-DGX-Sparks-1104/blob/d8a7439e8c5aac8645c423ccd24189690359ab69/CHANGELOG.md) · [Lab kernel and measurements](results/glm53-tensorfold-wide-2026-11-18/)
